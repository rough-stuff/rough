# 导演手册：怎么让画面有“人味”

写分镜之前读完这一篇。技术上怎么写在 [reference.md](reference.md)，这里只讲怎么想。

## 一、先想清楚你在模仿什么

一个人站在白板前给朋友讲一件事。他会：

- **说到什么，手就画什么。** 不会提前把整板画好，也不会说完半天才动笔。
- **画的是事情本身，不是他说的话。** 讲“钱转了一圈”，他画的是一个圈和一张钱，不会写“钱转了一圈”五个字。
- **在已有的画上继续加。** 圈一下、划掉、加个箭头、在旁边补个数字。板面是慢慢长出来的。
- **板面满了才擦，或者走到旁边一块干净的地方。**
- **手不会停太久。** 哪怕只是在重点上点两下。

观众觉得“没人味”，几乎总是因为违反了上面某一条。

## 二、每句话问自己三个问题

1. **这句话里的“东西”是什么？** 人、机构、钱、货、机器、时间、数字。每个东西给它一个固定的长相和位置。
2. **这些东西之间发生了什么？** 给、拿、涨、跌、变多、消失、挡住、绕开。这才是要画的——用**移动、箭头、变形、擦除**来表现。
3. **观众此刻该看哪儿？** 用画的顺序、圈、镜头推近来指挥视线。

如果一句话问完三个问题还是只想到“写几个字”，说明还没想透，再想。

## 三、把话变成画的常用手法

| 口播在讲 | 别这样 | 这样 |
|---|---|---|
| A 把钱给 B | 写“A→B 100元” | 画 A 和 B，钞票从 A 手里**滑**到 B 手里 |
| 一圈下来没赚 | 写“净收益为零” | 钞票绕一圈回到原点，原点上写个大大的“+0” |
| 某个数很低 / 在跌 | 写一句结论 | 折线画到那个点，把点涂红，小人吓一跳 |
| 被砍掉七成 | 写“削减 70%” | 先画一根高柱子，再在旁边画一根矮的；或者把高柱子**擦掉**一大截 |
| 有人觉得 / 很多人说 | 写“观点：……” | 小人头上冒一个想法泡泡，泡泡里画个图标 |
| 这个说法站不住 | 写“结论：错误” | 在刚才画的东西上打个红叉，小人摊手 |
| 两件事对比 | 左右各列三条要点 | 左右各画一个场面，中间一条线，同一个小人在两边表情不同 |
| 原因 → 结果 | 写“因为…所以…” | 画出原因，画箭头，再画出结果；箭头落笔卡在“所以”上 |
| 抽象概念（谈判筹码、话语权） | 写出这个词再解释 | 找一个能拿在手里的东西代表它（筹码、话筒、天平），之后一直用它 |
| 时间流逝 / 历史 | 写年份列表 | 画一条时间线，小人沿着线走，走到哪儿画到哪儿 |
| 强调一句金句 | 整句写在屏幕中央 | 把全片出现过的关键画面留在板上，只圈出其中最要紧的那一个；金句留给字幕和声音 |

**板书的正确用途：** 名字标签（公司、政府）、数字（100、53%、+0）、2–5 个字的关键词（“谈判题”）。数字是画面的一等公民，要写大、写醒目。

## 四、小人是讲述者的替身

全片最好有一个贯穿的小人。它不是装饰，它替观众做反应：

- 讲到反常的事 → `face: surprised`
- 讲到“你可能会说” → 小人 `think` 或头上冒问号
- 讲到坏消息 → `slump`、`worried`
- 指向重点 → `point-right` / `point-up-left`
- 得出结论 → `shrug`（无奈）或 `cheer`

姿势和表情的切换几乎不花时间（0.3 秒），是填补“画面静止”最便宜、最有人味的办法。

用配饰区分角色：老板戴礼帽（`tophat`）拎公文包，工人戴安全帽（`hardhat`），学者戴眼镜。同一个角色在全片保持同一套打扮。

## 五、节奏

- **一拍只做一件事。** 一拍大约对应半句到一句话（1–2.5 秒）。口播每秒 4–5 个字，一拍的时间只够画一个小人、或一个图标、或写三四个字。
- **复杂的图拆开。** 三个角色分三拍画，每个角色卡在提到它的那个词上。
- **善用停顿。** `hj brief` 里列了每句后面的停顿。转场、擦板放在停顿里；下一句要画的大东西可以用 `lead` 提前半秒起笔。
- **检查器说“画得太赶”时**，不要只是加 `dur`。问自己：这一拍是不是塞了两件事？这个图是不是能更简单？
- **检查器说“静止太久”时**，那几秒在说什么？给它一拍：小人换个动作、在已有的东西上圈一下、推一下镜头。

## 六、板面与镜头

- 一个场景就是一块板面。一个场景讲一件完整的事，通常 10–30 秒。
- **把板面用满。** 手机上看，小东西等于没画。主角元素的尺寸通常是板面短边的 30%–50%。
- 话题延续 → 留在同一个场景里继续加。
- 换话题 → 新场景，`enter: pan`（像走到白板的另一边）。
- 推翻前面的说法、从头再来 → `enter: wipe`（擦掉重画，本身就是一个表态）。
- 板面上东西多、此刻只讲其中一个 → `camera: {focus: [...]}` 推近，讲完 `camera: home` 拉回。
- 同一个东西第二次出现时，尽量长得一样、位置一致。观众靠这个认人。

## 七、竖屏和横屏

- 竖屏（960×1250 的画板）：上下分区。常见布局是上面一个大场面、下面一行结论；或者从上到下的流程。
- 横屏（1700×800 的画板）：左右分区。适合对比、时间线、从左到右的流程。
- 一份分镜只针对一种画幅。换画幅需要重新摆位置，但 `beats` 基本可以原样保留。

## 八、交稿前自查

`hj stills` 之后，逐张看联系表，问：

1. 关掉声音只看画面，能看懂大概在讲什么吗？
2. 有没有哪一帧像 PPT（整齐的文字块、居中的标题）？
3. 每一拍和上一拍相比，画面上有没有新东西或新动作？
4. 有没有东西太小、互相压住、贴着边？
5. 最后一帧是不是一幅完整的、能代表这个场景的画？
